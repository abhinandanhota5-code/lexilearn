SUPPORT & TROUBLESHOOTING
================================================================================

Git Issues:
  • Merge conflicts → See TEAM_COLLABORATION_PLAN.md Part D (Handling Conflicts)
  • Branch not updating → git fetch origin && git pull origin BRANCH-NAME
  • Wrong branch → git checkout CORRECT-BRANCH
  • Need to see changes → git diff origin/main...feature/YOUR-BRANCH

Development Issues:
  • npm start fails → rm -rf node_modules && npm install && npm start
  • Baseline test fails → node ipp-mvp-demo.js (check console for errors)
  • Feature breaks baseline → Revert commit and debug
